# braun-radio

## Purpose

Interactive 3D radio collection featuring the Braun RT 20, Lexon Tykho, and Tivoli Model One built with Three.js and Web Audio API.

## Ownership

Independent Vite + Three.js project.

## Local Contracts

- Vite + Three.js + Web Audio API. Plain JavaScript / ES modules.
- Work inside this directory (`/Users/acchuang/Project/braun-radio`).

## Work Guidance

- Dev: `npm run dev`
- Build: `npm run build`
- Preview: `npm run preview`
- Deploy: `npm run deploy` (Cloudflare Pages: https://braun-radio.pages.dev)
